# Imágenes del Proyecto

## default-avatar.png

Esta carpeta debe contener la imagen `default-avatar.png` que se utilizará como avatar por defecto para todos los usuarios del sistema.

### Especificaciones de la imagen:
- **Nombre del archivo:** `default-avatar.png`
- **Tamaño recomendado:** 512x512 píxeles
- **Formato:** PNG con fondo transparente
- **Peso máximo:** 100KB

### Dónde obtener la imagen:
Puedes usar cualquiera de estas opciones:
1. **Crear un avatar personalizado:** Usa generadores en línea como:
   - https://avatar.oxro.io/
   - https://www.flaticon.com/
   - https://www.canva.com/

2. **Usar un icono de usuario genérico:** Busca "user avatar icon" en sitios como:
   - https://www.flaticon.com/
   - https://icons8.com/
   - https://www.iconfinder.com/

3. **Diseño personalizado:** Crea tu propio avatar con el logo de AUTONEW

### Instrucciones:
1. Descarga o crea tu imagen de avatar
2. Renómbrala como `default-avatar.png`
3. Colócala en esta carpeta: `lavado_auto/static/images/`
4. Asegúrate de que la imagen esté optimizada (no más de 100KB)

**IMPORTANTE:** Sin esta imagen, el perfil de usuario mostrará un error al cargar. Asegúrate de agregar la imagen antes de ejecutar el proyecto.
